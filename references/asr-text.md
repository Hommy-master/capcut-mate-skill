# asr_text（语音转文本）

```
POST https://autosubrt.jcaigc.cn/openapi/autosubrt/v1/asr/text
```

> 依据官方接口文档 https://docs.jcaigc.cn/capcut-mate/ 整理。
> **这是独立的语音识别服务**：基地址 `https://autosubrt.jcaigc.cn`，路径前缀 `/openapi/autosubrt/v1/`。

## 功能描述

把音频识别成**带标点的纯文本**并直接返回，不带任何时间线。只要文案、不关心时间时用它，响应体最小。
需要分句与逐字时间线用 [asr](asr.md)，需要 SRT 字幕文件用 [asr_srt](asr-srt.md)。

## 请求参数

```json
{
  "audio_url": "https://example.com/audio.mp3",
  "apiKey": "123e4567-e89b-12d3-a456-426614174000"
}
```

### 参数说明

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| audio_url | string | ✅ | - | 音频文件 URL，需可被服务端直接下载 |
| apiKey | string | 开启计费时必填 | - | 合法 UUID；可登录 <https://jcaigc.cn> 获取 |

`audio_url` 支持常见音视频文件（wav、mp3、m4a、aac、flac、ogg、mp4、mov 等），单文件最大 100MB。

## 响应格式

### 成功响应 (200)

```json
{
  "code": 0,
  "message": "成功",
  "data": {
    "text": "你们应该都听过啊，羊毛羊绒当中的软黄金。"
  }
}
```

### 响应字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| code | int | 0 表示成功 |
| message | string | 提示信息 |
| data.text | string | 识别出的完整文案，**一定带标点**；没有识别到语音时为空字符串 |

### 错误响应

```json
{
  "code": 2003,
  "message": "下载文件失败"
}
```

错误体**不包含** `data` 字段；所有错误都返回 HTTP 200，需按 `code` 判断。

## 计费

按**音频时长**扣费：**0.00022 元/秒**，识别成功后才扣费；与剪映小助手共用充值余额。

## 错误码说明

与 [asr](asr.md) 相同的主要错误码：

| 错误码 | 错误信息 | 说明 | 解决方案 |
|--------|----------|------|----------|
| 1001 | 参数校验失败 | apiKey 不是合法 UUID | 检查请求参数 |
| 2001 | 识别音频失败 | 音频无法解码或地址不可访问 | 换可访问的直链或可播放文件 |
| 2002 | 文件大小超出限制 | 音频超过 100MB | 压缩或截取后再试 |
| 2003 | 下载文件失败 | 下载过程中网络或服务端错误 | 确认是公网可直链下载的地址 |
| 2005 | 下载文件超时 | 下载整体超时 | 换更快的源或更小的文件 |
| 2035 | 充值余额不足 | 余额不足 | 充值后重试 |
| 2036 | 无效的 apiKey | 计费开启时未传 apiKey | 登录 <https://jcaigc.cn> 获取 |
| 9997 | 服务器忙 | 并发已达上限 | 稍后重试 |
| 9998 | 系统内部错误 | 未预期的内部异常 | 联系技术支持 |
| 9999 | 未知异常 | 计费服务不可用等 | 稍后重试 |

## 注意事项

1. **`audio_url` 不做 URL 格式校验**：传空值或非 URL 字符串会在下载阶段失败并返回 2003。
2. **只返回文本**：没有任何时间信息。需要分句和逐字时间线请改用 [asr](asr.md)。
3. **没有识别到语音**时返回成功、`data.text` 为空字符串。
4. **重复调用会重复扣费**，超时后请勿盲目重试。
